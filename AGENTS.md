# Repository workflow

The repository owner requires all work to stay on `main`. Do not create separate development or APK branches unless the owner explicitly changes this instruction.

Keep only the latest published APK and its checksum under `releases/<release-tag>/` on `main`. Remove superseded APK folders and obsolete GitHub release listings when publishing a replacement. Update the repository README and GitHub release download links when publishing or moving an APK. Preserve historical Git tags unless the owner explicitly requests their removal; do not keep older APK downloads in the current tree.
